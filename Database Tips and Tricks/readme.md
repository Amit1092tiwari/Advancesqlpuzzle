# Database Tips and Tricks

This directory contains useful T-SQL utility functions, stored procedures, and techniques for enterprise database engineering:

- **[Calendar Table](./Calendar%20Table/)**: Functions and documentation for generating deterministic, high-performance calendar dimension tables.
- **[Data Profiling](./Data%20Profiling/)**: Comprehensive data profiling scripts for metadata analysis, null percentages, data type validation, and statistical distribution.
- **[Pivoting Data](./Pivoting%20Data/)**: Dynamic pivoting stored procedure (`SpPivotData`) and examples.
- **[Subtracting Two Dates](./Subtracting%20Two%20Dates/)**: High-precision date difference routines returning intervals as string or table rows (`FnDateDiffPartsChar`, `FnDateDiffPartsTable`).
