# Microsoft Azure Data Engineering Demos

This directory contains cloud architecture demonstrations, end-to-end data pipelines, slide presentations, and DDL scripts for Microsoft Azure data services.

---

## Contents

### 1. [Azure Data Factory Metadata Demo](./Data%20Factory%20Metadata%20Demo/)
- **Document:** `Data Factory Metadata Demo PDF.pdf`
- **Scripts:** `Data Factory SQL DDL Scripts.sql`
- **Data:** `Customer_1.txt`, `Customer_2.txt`, `Customer_3.txt`
- **Overview:** Demonstrates automated metadata capture, dynamic pipeline auditing, and Table-Valued Parameter (TVP) data loading in Azure Data Factory (ADF) connecting to Azure SQL.

### 2. [Databricks Spark Hive Demo](./Databricks%20Spark%20Hive%20Demo/)
- **Document:** `Azure Databricks Spark Hive Demo PDF.pdf`
- **Workspace:** `SuppliersAndParts.dbc` (Databricks export)
- **Scripts:** `SuppliersAndPartsDDL.sql`
- **Data:** `Suppliers.csv`, `Parts.csv`, `Shipments.csv`
- **Overview:** Demonstrates Azure Databricks Spark SQL and Hive metastore integration using the classic Suppliers-Parts-Shipments relational model.
